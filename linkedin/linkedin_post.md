**Heart Disease Prediction – Synthetic Dataset** 

I just completed a data visualization and machine learning prep project that I am excited to share.

**The Problem:**
Heart disease is one of the leading causes of death worldwide. For beginners entering data science, finding clean, well-structured datasets to practice on can be challenging. Real clinical data has privacy restrictions, and many practice datasets lack realistic risk-factor relationships.

**My Solution:**
I created a synthetic heart disease prediction dataset with exactly 100 patient records and 20 clinical features. The data was generated algorithmically using probabilistic risk-factor relationships inspired by the real CDC BRFSS 2015 survey dataset.

**What makes this dataset different:**

- 100 unique synthetic patients (P001 to P100)
- 20 clinically meaningful features (age, cholesterol, blood pressure, ECG, ST depression, etc.)
- Balanced target distribution (46 positive / 54 negative)
- Risk-factor relationships that mirror real-world patterns
- Probabilistic scoring, not deterministic rules

**What I built:**

- Python data generation pipeline with reproducible random seed
- Comprehensive validation (all 10 checks PASS)
- 14 professional visualizations plus a summary dashboard
- Complete project documentation
- Kaggle publication: arulmariaagnes/synthetic-heart-disease-100
- GitHub portfolio: github.com/ArulAgnes/Data-Visualization-Heart-disease

**Key Learning:**
Designing realistic synthetic data requires understanding the domain. I studied how age, smoking, diabetes, BMI, and other factors relate to heart disease risk, then implemented these relationships probabilistically rather than using hard rules.

**Important caveat:**
This is synthetic data for educational purposes only. It does not represent real patients and should not be used for medical diagnosis.

Tools: Python, Pandas, NumPy, Matplotlib, Seaborn
Platforms: Kaggle, GitHub
